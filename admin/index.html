    🔗 URL Construction Rules

    ✅ Rule 1 — Movie / Album Song:

    Use when the song is from a movie or named album:

    url128: https://pagalfree.com/dwload/128-[Song]%20-%20[Album]%20128%20Kbps.mp3
    url320: https://pagalfree.com/dwload/320-[Song]%20-%20[Album]%20320%20Kbps.mp3
    img128: https://pagalfree.com/images/128[Song]%20-%20[Album]%20128%20Kbps.jpg
    img320: https://pagalfree.com/images/320[Song]%20-%20[Album]%20320%20Kbps.jpg

    ✅ Rule 2 — Single / Indipop / Punjabi:

    Use when the album name = song name, or no specific movie:

    url128: https://pagalfree.com/dwload/128-[Song]%20-%20[Artist]%20128%20Kbps.mp3
    url320: https://pagalfree.com/dwload/320-[Song]%20-%20[Artist]%20320%20Kbps.mp3
    img128: https://pagalfree.com/images/128[Song]%20-%20[Artist]%20128%20Kbps.jpg
    img320: https://pagalfree.com/images/320[Song]%20-%20[Artist]%20320%20Kbps.jpg

    ⚠ STRICT RULES — Never Break These:

    • All spaces → %20 (never use + or actual spaces in URLs)
    • 128kbps links use 128 prefix, 320kbps use 320
    • Audio files end in .mp3, images end in .jpg
    • img128/img320 have NO dash after the quality number (e.g. /images/128Song...)
    • url128/url320 have a dash after quality (e.g. /dwload/128-Song...)

    📤 How to Upload Songs to Database

    1. Go to Raw Editor tab in the sidebar.
    2. The editor shows all current songs as a JSON array.
    3. Add new song objects to the array following the format above.
    4. Click Auto-Fix & Validate — this fixes common errors (missing quotes, trailing commas, etc.).
    5. If no red error appears, click Save & Overwrite Database.
    6. ⚠ Warning: Saving overwrites ALL existing songs. Always keep a backup.

    💡 Tip: To add just one song, go to Songs tab → click Add Song button. Fill the form. Much safer than Raw Editor.
